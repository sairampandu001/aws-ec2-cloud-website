☁️ Project Implementation

This project demonstrates the deployment of a cloud-hosted website using AWS EC2.

An EC2 instance was launched in the Asia Pacific (Hyderabad) region using Amazon Linux 2023. Secure server access was configured using an SSH key pair.

Inside the server environment, Linux commands such as cd, ls, and pwd were used to navigate directories including:

/etc – system configuration /var – system data and logs /var/www/html – Apache website root directory

The Apache HTTP Server (httpd) was installed and configured to host the website by deploying the HTML page inside the document root directory.

SSH Access .pem Key Linux Commands Apache httpd DNF Package Manager systemctl

🔐 Security & Networking

To allow secure connectivity and public access to the website, EC2 Security Group rules were configured.

SSH - Port 22 HTTP - Port 80 HTTPS - Port 443

These rules allow secure remote server access and enable web traffic to reach the Apache web server.

🌐 Domain & SSL Configuration

The domain buciiii.com was connected to the EC2 server using DNS configuration through GoDaddy.

An A Record was configured to map the domain to the EC2 Elastic IP address.

HTTPS security was implemented using Let's Encrypt Certbot, generating SSL certificates to enable encrypted communication.

DNS A Record Elastic IP Certbot Let's Encrypt HTTPS
