📘 Architecture Explanation

When a user accesses the domain buciiii.com, the DNS records resolve the domain to the EC2 Elastic IP address. The request reaches the EC2 server where the Apache web server processes the request and serves the website files located in /var/www/html.

sudo dnf install httpd

🛠 Problems Faced & Troubleshooting

During deployment the website was initially not accessible through the browser. Troubleshooting included checking EC2 instance status, verifying Apache service status, reviewing security group rules and checking DNS configuration.

Network diagnostics using ping and tracert helped identify a routing issue which was later resolved.
