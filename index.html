📘 Deployment Implementation

A cloud server was created using Amazon EC2 with instance type t3.micro running Amazon Linux 2023.

SSH connection:

chmod 400 key.pem

ssh -i key.pem ec2-user@IP_ADDRESS

Website deployment:

sudo nano /var/www/html/index.html

Apache installation:

sudo dnf install httpd

sudo systemctl start httpd

sudo systemctl enable httpd

🔐 Security & Networking

Security group rules allow:

Port 22 – SSH

Port 80 – HTTP

Port 443 – HTTPS

🌐 Domain & DNS Configuration

The domain buciiii.com was purchased from GoDaddy and mapped to the EC2 Elastic IP address using DNS records.

A record: buciiii.com → Elastic IP

CNAME: www.buciiii.com → buciiii.com

🔒 HTTPS Security

SSL certificates were generated using Certbot.

sudo dnf install certbot

sudo certbot certonly -d buciiii.com -d www.buciiii.com -d test.buciiii.com
