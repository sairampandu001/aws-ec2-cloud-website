🚀 Project Overview

This project demonstrates a cloud-based web server deployment on AWS implemented using Amazon EC2 and the Apache HTTP Server.

The objective of this project was to design and implement an end-to-end cloud hosting environment including server provisioning, networking configuration, domain mapping, SSL security and version-controlled updates.

  • Deploying a cloud server on AWS EC2
  • Installing and configuring the Apache web server
  • Deploying website content on a Linux server
  • Connecting a custom domain
  • Configuring DNS records for domain integration
  • Securing the website using HTTPS with SSL certificates
  • Managing project updates using Git and GitHub

📊 Project Infrastructure Summary

Cloud Platform: Amazon Web Services

Compute Service: Amazon EC2

Instance Type: t3.micro

Operating System: Amazon Linux 2023

Web Server: Apache HTTP Server

Domain Provider: GoDaddy

Security: HTTPS using Certbot & Let's Encrypt

Version Control: Git & GitHub
