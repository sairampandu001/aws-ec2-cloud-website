📂 Projects

AWS EC2 Cloud Web Server Deployment

This project demonstrates the end-to-end deployment of a cloud-hosted website using AWS cloud services.

The website is hosted on an AWS EC2 instance running Amazon Linux 2023 with an Apache HTTP Server. A custom domain was configured using GoDaddy DNS and secured with HTTPS using Let's Encrypt SSL certificate.

Key Implementation Steps

  • Launched an EC2 instance in the AWS cloud
  • Configured SSH access for secure server login
  • Installed and configured the Apache HTTP web server
  • Deployed website files to /var/www/html
  • Connected custom domain buciiii.com
  • Configured DNS using GoDaddy (A Record → Elastic IP, CNAME → www)
  • Enabled HTTPS security using Certbot and Let's Encrypt
  • Managed project code using Git and GitHub

📘 Architecture Explanation

When a user accesses buciiii.com, the DNS resolves the domain to the Elastic IP associated with the AWS EC2 instance. The request reaches the Apache web server running on EC2, which serves the website files from the /var/www/html directory.

🗂 Project Implementation Timeline

Launch EC2 Instance → Install Apache → Deploy HTML Website → Configure DNS → Enable HTTPS Security → Setup Git Version Control

📦 Deployment Implementation Commands

Apache HTTP Server was installed and configured on the EC2 instance using the Amazon Linux package manager and systemctl service management. 

sudo dnf install httpd
sudo systemctl start httpd
sudo systemctl enable httpd

🛠 Problems Faced & Troubleshooting

During deployment, troubleshooting included verifying EC2 instance status, checking Apache service configuration, validating security group rules, testing DNS records, and diagnosing network connectivity issues to ensure the website was publicly accessible.
