📂 Projects

AWS EC2 Cloud Web Server Deployment

This project demonstrates the end-to-end deployment of a cloud-hosted website using AWS cloud services.

The website is hosted on an AWS EC2 instance running Amazon Linux 2023 with an Apache web server. A custom domain was configured using GoDaddy DNS and secured with HTTPS using a Let's Encrypt SSL certificate.

Key Implementation Steps

  • Launched an EC2 instance in the AWS cloud
  • Configured SSH access for secure server login
  • Installed and configured the Apache web server
  • Deployed website files to /var/www/html
  • Connected the custom domain buciiii.com
  • Configured DNS using GoDaddy (A Record and CNAME)
  • Enabled HTTPS security using Certbot and Let's Encrypt
  • Managed project code using Git and GitHub

📘 Architecture Explanation

When a user accesses buciiii.com the DNS resolves to the Elastic IP of the EC2 instance and Apache serves the website files from /var/www/html.
